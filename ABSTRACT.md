# Abstract

The AI Resume Analyzer is a web-based decision-support tool that helps job applicants tailor resumes to a target vacancy. The system accepts a resume in PDF, DOCX, or DOC format and a job description supplied either as pasted text or an uploaded document. It extracts document text, checks ATS-oriented structure and formatting, identifies domain skills and important job keywords, and computes lexical and semantic alignment. The NLP pipeline combines rule-based phrase matching, spaCy token processing, a configurable skills taxonomy, and Hugging Face MiniLM embeddings. An explainable weighted score summarizes ATS compatibility, keyword coverage, skill alignment, and semantic similarity, while the interface separately displays each component and provides actionable recommendations. A TF-IDF fallback permits operation when the transformer model is unavailable. The prototype is implemented in Python and Streamlit with PyPDF2 and python-docx for document ingestion. It does not claim to reproduce any proprietary ATS; rather, it provides transparent guidance that users can verify. The modular design supports future additions including OCR, multilingual analysis, authenticated history, recruiter dashboards, occupation-specific taxonomies, and outcome-based validation.

**Keywords:** Applicant Tracking System, resume analysis, natural language processing, semantic similarity, Hugging Face, Streamlit, skill matching.
